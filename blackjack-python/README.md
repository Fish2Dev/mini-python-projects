## ⚡ Installation & Quick Start
```bash
# 1. Navigate to this project's directory
cd blackjack-python

# 2. Run the application
python blackjack.py

# 3. Go back to the root folder when finished
cd ..
```

## ⚙ Features
* **Feature 1:** Runs through one full game of blackjack with the ability being able to hit and stand.
* **Feature 2:** Includes an enemy AI bot to play against you.
* **Feature 3:** Has a win/lose and bust result system.

## 🕹️ How to Use & Controls
* **Step 1:** When you get dealt your cards, type "hit" or "stand".
* **Step 2:**
  * **Hit:** Once you get dealt a new card, decide whether to "hit" or "stand".
  * **Stand:** Wait for the bot to dealt cards and the program to decide who won.
* **Step 3:**
  * **Bust:** If you bust and go over 21, the program will quit, run it again to play.
  * **Win Or Lose:** Once you figure out if you win or lose, type "yes" to see the bot's cards or type "no" to end.
* **Step 4:** The program will automatically quit once the game ends, run it again to play.
* **Controls Reference:**
  * Type "hit" to get dealt another card.
  * Type "stand" to lock in your current score.
  * After a game is done, type "no" to end the program.
  * After a game is done, type "yes" to see the bot's cards and end the program.

## 🛠️ Tech Stack & Concepts

* **Standard Modules:** sys (for quitting)
